# TypeScript & Node.js Richtlinien

1. **Typisierung**:
   - Strikter TypeScript-Modus (`strict: true`).
   - Vermeide den Typ `any`; verwende `unknown` oder dedizierte Interfaces / Types.

2. **Testing & Tools**:
   - Tests mit `vitest` schreiben und ausführen.
   - Linter-Prüfungen mit ESLint und Formatierung mit Prettier sicherstellen.
